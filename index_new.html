Pengenalan Dasar-Dasar Cloud Computing ปูพื้นฐาน Cloud Computing

Sebelum bicara AI, kita mulai dari pahami konsep dasar cloud computing, bagaimana komputasi modern bekerja. ก่อนจะเริ่มเรื่อง AI เรามาทำความเข้าใจแนวคิดพื้นฐานของคลาวด์ และการทำงานของระบบคอมพิวเตอร์ยุคใหม่กันก่อน

☁️

Apa itu Cloud Computing? Cloud Computing คืออะไร?

Menurut definisi Amazon Web Services: layanan komponen IT secara on-demand yang dapat diakses di mana pun melalui internet, dengan biaya pay-as-you-go — bayar sesuai pemakaian. คำจำกัดความจาก AWS: บริการโครงสร้างพื้นฐานไอทีแบบตามสั่ง (on-demand) ที่เข้าถึงได้ทุกที่ผ่านอินเทอร์เน็ต โดยจ่ายเงินเท่าที่ใช้งานจริง (pay-as-you-go)

🟠

Apa itu AWS? AWS คืออะไร?

Platform cloud computing dengan market share terbesar di dunia — sekitar 32%. Digunakan perusahaan besar seperti Airbnb, Netflix, Twitch, dan Twitter. Berada di bawah Amazon (didirikan 1994), AWS lahir tahun 2006. แพลตฟอร์มคลาวด์ที่มีส่วนแบ่งการตลาดสูงที่สุดในโลก (ประมาณ 32%) ซึ่งบริษัทชั้นนำอย่าง Airbnb, Netflix, Twitch และ Twitter เลือกระบบนี้ โดย AWS อยู่ในเครือ Amazon และเปิดตัวมาตั้งแต่ปี 2006

Introduction to Generative Artificial Intelligence

AI sudah ada sejak 1950-an. Generative AI adalah babak terbarunya — dan yang menjadi dasar bagi Kiro. AI มีมาตั้งแต่ยุค 1950 แต่ Generative AI คือยุคใหม่ล่าสุด — และเป็นหัวใจสำคัญของ Kiro

1950s
Artificial Intelligence Human intelligence exhibited by machines ปัญญาประดิษฐ์ที่แสดงความสามารถในการคิดเหมือนมนุษย์
1980s
Machine Learning AI systems that learn from historical data ระบบ AI ที่เรียนรู้และจดจำจากข้อมูลในอดีต
2010s
Deep Learning Machine learning models that mimic human brain function โมเดลการเรียนรู้ที่จำลองการทำงานของสมองมนุษย์
2020s
Generative AI Foundation models yang menciptakan konten orisinal โมเดลพื้นฐานที่สามารถสร้างสรรค์คอนเทนต์ใหม่ขึ้นมาได้เอง

Dasar Kiro พื้นฐาน Kiro

Pengenalan Kiro ทำความรู้จักกับ Kiro

"Bring engineering rigor to agentic development." Kiro adalah agentic IDE dari AWS, ditenagai Amazon Bedrock. "ยกระดับการพัฒนา Agentic AI ให้มีมาตรฐานเชิงวิศวกรรม" Kiro คือ Agentic IDE จาก AWS ขับเคลื่อนด้วย Amazon Bedrock

🧠 Apa itu Agentic AI? 🧠 Agentic AI คืออะไร?

Sebelum masuk ke Kiro, kenalan dulu dengan konsep di baliknya. Kiro adalah contoh dari Agentic AI — AI yang tidak cuma menjawab pertanyaan, tapi bisa bertindak untuk mencapai tujuan Anda, langkah demi langkah, secara mandiri. ก่อนเริ่มใช้ Kiro มาทำความเข้าใจแนวคิดนี้กันก่อน Kiro คือตัวอย่างของ Agentic AI — AI ที่ไม่ได้ทำแค่ตอบคำถาม แต่สามารถลงมือทำเพื่อบรรลุเป้าหมายที่คุณตั้งไว้ได้เองทีละขั้นตอน

🧠 LLM

Large Language Model — bagian yang berpikir. Memahami permintaan Anda, menyusun rencana, dan memutuskan langkah apa yang perlu diambil selanjutnya. Large Language Model — ส่วนที่ทำหน้าที่ "คิด" เข้าใจสิ่งที่คุณต้องการ วางแผน และตัดสินใจขั้นตอนถัดไป

🛠️ Tools

Kemampuan nyata untuk bertindak — menulis file, menjalankan terminal, browsing web. Tanpa tools, AI hanya bisa "berbicara", tidak bisa "mengerjakan". เครื่องมือในการ "ลงมือทำ" — เขียนไฟล์ รันคำสั่ง ค้นเว็บ หากไม่มีเครื่องมือ AI จะทำได้แค่พูดคุย แต่ทำงานจริงไม่ได้

🎯 Goal

Hasil akhir yang ingin dicapai — misalnya "buat website toko online". Goal inilah yang menuntun setiap keputusan LLM dan penggunaan tools. เป้าหมายที่ต้องการ — เช่น "สร้างเว็บร้านค้าออนไลน์" เป้าหมายนี้จะคอยนำทางให้ AI เลือกใช้เครื่องมือได้อย่างถูกต้อง

Specs

Mengubah ide jadi requirements, design, dan tasks — inti dari Spec-Driven Development. แปลงไอเดียให้เป็นข้อกำหนด ดีไซน์ และงานย่อย — หัวใจของ Spec-Driven Development

🧭

Steering

File panduan agar AI konsisten dengan standar tim dan proyek yang dikerjakan. ไฟล์คู่มือที่ช่วยให้ AI ทำงานได้ตรงตามมาตรฐานของทีมและโปรเจกต์

🪝

Agent Hooks

Otomatisasi yang berjalan sendiri saat peristiwa tertentu terjadi, misalnya file disimpan. ระบบอัตโนมัติที่ทำงานทันทีเมื่อมีเหตุการณ์ที่กำหนด เช่น เมื่อกดบันทึกไฟล์

Kapan Pakai Specs vs Vibe Coding? ควรเลือกใช้ Specs หรือ Vibe Coding ตอนไหน?

Gunakan Specs ✅ ใช้ Specs เมื่อ ✅

Fitur kompleks banyak komponen, risiko tinggi, butuh dokumentasi tim, proyek jangka panjang, multi-developer. ทำฟีเจอร์ซับซ้อน มีความเสี่ยงสูง ต้องมีเอกสารให้ทีม หรือทำโปรเจกต์ระยะยาวที่มีนักพัฒนาหลายคน

Gunakan Vibe Coding ✅ ใช้ Vibe Coding เมื่อ ✅

Eksplorasi cepat, script 1–2 file, bug fix yang jelas penyebabnya, tugas one-off, belajar sambil main. ต้องการทดลองไวๆ เขียนสคริปต์สั้นๆ แก้บั๊กจุดเล็กๆ หรือทำโปรเจกต์เล่นสนุกๆ
